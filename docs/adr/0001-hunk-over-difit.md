# difit ではなく hunk を差分ビューアに採用する

プリフライトレビューの差分表示に、ブラウザで GitHub の Files changed 相当の画面を出す difit ではなく、ターミナル TUI の hunk を選んだ。理由は 2 つある。ひとつは herdr のワークスペースとタブでレビュー環境を組み立てる設計を採ったこと。difit はブラウザに出るためこの管理下から外れる。もうひとつは `hunk session` API の存在で、レビューメモを `sessionId` 単位で機械的に回収できるのは hunk だけである。

見た目の GitHub 再現度では difit が勝る。それでも hunk を採ったのは、このツールの価値が「差分をきれいに見せること」ではなく「herdr の中でレビュー環境が一式組み上がり、付けたメモが修正作業に繋がること」にあるためである。

この判断はワークスペース構成、セッション識別方式、レビューメモの回収経路すべての前提になっている。ビューアを差し替えるとツールの大半が書き直しになる。
