# レビューメモをポーリングで保持する

Hunk セッションは TUI が終了した瞬間に消滅し、そこに付いていたレビューメモも一緒に失われる。実測で確認済みで、herdr のワークスペースを閉じた直後に `hunk session list` は `No active Hunk sessions.` を返した。

したがって control タブで Enter を押した時点でメモを取りに行く方式は成立しない。先に hunk を閉じたレイヤーのメモが丸ごと落ちる。レビュー中は「まだ閉じないでください」と利用者に制約を課すことになり、これは使い勝手を損なう。

そこで control タブのプロセスが待機中に 2 秒間隔で全セッションの `comment list --type user` を取り続け、最新のスナップショットを保持する。hunk をいつ閉じても、閉じる直前のメモが残る。

イベント駆動でないのは、hunk 側にセッション終了前の通知機構が無いためである。ポーリング間隔の 2 秒は、人間がメモを付けてから hunk を閉じるまでの最短時間より十分短いという判断による。
